# Glossário

- **NF**: nota fiscal de serviço da estadia (NFS-e).
- **Tomador**: quem aparece na nota (pessoa ou empresa), com CPF/CNPJ e endereço.
- **Solicitação**: pedido de NF que vem pelo formulário do hotel.
- **Tratativa**: conversa com o hóspede para acertar dados da nota.
- **Nota dividida**: o hóspede pede mais de uma nota (ex.: 2 quartos). Etiqueta azul no Outlook.
- **Planilha Central**: a planilha do Google onde tudo se junta ("Planilha Central! (Krz)").
- **Robô**: o programa que manda as solicitações por e-mail.
- **Conferente**: o programa que lê o Outlook de cada PC, liga e-mail ↔ pedido e acha a NF.
- **Espelho**: o Painel mostra o que está no Outlook agora; não guarda nada.
- **Mail Analytics (MA)**: o outro sistema, que conta e-mails, ligações e NFs por agente/dia. Só leitura.
- **Saúde**: a faixa de avisos no topo do Painel.
- **Modo Professor**: frases azuis embaixo dos botões explicando o que fazem.
- **Commit / push / branch**: salvar uma versão do código / mandar para o GitHub / a "cópia" de cada PC.
